# Art for the landing — batch 1

Twelve prompts, in the order the landing needs them. These are the articles
that recur most across the next year of weeks: #1177 surfaces 22 times, #855
twenty, #858 eighteen. Art for these twelve does more for the page than art
for any other twelve.

**Why they are needed at all.** Of the 635 articles in the landing pool, 123
own a photograph. The rest were being given generic department art — a parsha
picture on *Noah's Ark and Haman's Gallows*, a sichah picture on a flood
piece — which told the reader nothing. That is now switched off, so these
cards run as type until there is something true to put on them.

**Standing rules these follow.** No likeness of the Rebbe and no identifiable
real person. Dress named explicitly every time. No mixed-gender crowds in a
religious setting. Everyone is doing something and gesturing naturally —
nobody stands blank or posed.

**House look**, appended to every prompt so the set coheres with the site's
cream-and-ink palette:

```
muted archival palette, warm cream paper and deep blue-black ink, restrained brass accent, documentary editorial illustration, soft directional window light, grainy film texture, no lettering, no text --ar 16:9 --style raw --v 7
```

Save each as `storage/art/cards/<slug>.jpg`, then set `"img"` on the article
or drop it in `ART_CARDS` — either way `ART_FOR_CARDS` stays off, so nothing
generic creeps back.
