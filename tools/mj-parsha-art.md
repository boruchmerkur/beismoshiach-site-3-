# Parsha art — the next seven sidras

One picture, `storage/art/parsha.jpg`, has been standing in for all fifty-four
sidras, and it is a sand dune. On 11 November it was the lead picture on a
Toldos piece about Philistine cynicism. The builder now prefers
`storage/art/parsha/<tag>.jpg`, keyed by the same tag the badge shows, so the
picture can never contradict the label. These fill the next seven weeks.

**Save each as** `storage/art/parsha/<tag>.jpg` — the tag is given under each
prompt. Nothing else to wire up; the next build picks them up.

**One prompt per box, no braces.** Brace permutations crammed every scene into
one panelled image on this account, so each sidra is submitted on its own.
No `--style raw` — it fails the batch on v8.2.

Scenes are drawn from what the sidra actually says. Nobody is identifiable,
no faces where a face would have to be invented, and everyone is doing
something.
